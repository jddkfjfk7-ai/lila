# Lila PHP Migration

This is the PHP implementation built alongside the original Lila source.

No existing Scala, TypeScript, configuration, test, translation, asset, or documentation file is deleted or replaced.

Phase 1 establishes the PHP 8.3 application kernel: PSR-4 autoloading, HTTP request/response objects, a lightweight router, an initial controller, and the PHP entry point.

Run with Composer from this directory, then start the PHP development server.
